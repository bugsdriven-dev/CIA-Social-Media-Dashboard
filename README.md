# Social Media Data Mining Dashboard

This project is an interactive data mining dashboard developed as part of **CIA 3.1**.  
It analyzes a real-world social media usage dataset to study user behavior and its impact on academic performance.

---

## 📌 Project Objective
The main objective of this project is to apply core data mining techniques to:
- Analyze social media usage patterns
- Discover hidden relationships between addiction, sleep, and academic performance
- Predict academic impact using classification models
- Segment users based on behavioral similarities

---

## 📊 Dataset Description
- Source: **Kaggle**
- Records: **705**
- Attributes: **13**
- The dataset includes demographic details, social media usage patterns, addiction scores, sleep hours, mental health indicators, and academic impact.

---

## 🛠️ Techniques Implemented
- **Data Preprocessing**
  - Duplicate removal
  - Missing value handling (mean imputation)
  - Normalization (Min–Max scaling)
  - Outlier detection (Boxplot, IQR)

- **Association Rule Mining**
  - Apriori Algorithm
  - Support, Confidence, Lift analysis

- **Classification**
  - Decision Tree Classifier
  - Naive Bayes Classifier
  - Accuracy and Confusion Matrix evaluation

- **Clustering**
  - K-Means Clustering
  - User behavior segmentation
